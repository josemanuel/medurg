# MedUrg Admin v2

Módulo administrativo funcional con flujo guiado de cinco fases, transiciones controladas e historial de estados.

## Ejecutar
```bash
python -m http.server 8081
```
Abrir `http://localhost:8081`.

Incluye `FUNCTIONAL_SPEC.md` y `workflow-history.schema.json`. Es un MVP local sin autenticación ni backend.
